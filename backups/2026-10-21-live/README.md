# Current live Corne configuration

This is a fresh Vial export from the connected Corne v4.1 standard keyboard on 21 October 2026. Vial refreshed the device before exporting. The six-layer export includes keymaps, encoders, macros, Tap Dance, combos, overrides, alternate repeat keys, and QMK tap/hold settings.

The file happens to match the earlier backup byte for byte. A new live export and comparison established that identity. No layout or device setting was written during capture.

Global lighting is recorded separately in capture.json because .vil does not contain RGB preferences. Effect, brightness, speed, and the red swatch were read from the live Lighting tab. The numerical colour value was not read in this capture.

The user reported installing the previously verified PR1 CI firmware on both halves. No installed flash dump or independent installed-binary verification was performed. Public metadata omits machine paths and device serials. All 16 macro slots are empty, and the export passed the publication-content audit.
